# 喵喵找家 🐱

一款适合 4–6 岁孩子玩的猫咪逻辑解谜游戏。孩子要把小猫放进彩色格子里，帮每只小猫找到家。

## 试玩

**手机或电脑打开：** [https://tusiman.github.io/meowsudoku/](https://tusiman.github.io/meowsudoku/)

## 怎么玩

- 每一行、每一列、每种颜色区域都要有一只小猫。
- 小猫之间不能相邻，斜角也算。
- 点空格放下一只猫，再点已放的小猫可以拿走。
- 可以使用“给提示”“检查棋盘”“拿走猫”和“重新开始本关”。
- 音效可以随时关闭；关卡进度和音效设置保存在当前浏览器中。

游戏共有 20 关，棋盘从 4×4 逐步增加到 6×6。前面的关卡会预先放好一些固定线索猫，之后逐渐减少，最后几关从空棋盘开始。

## 打印与答案

- “打印题目”可以勾选多个关卡，包括尚未在游戏中解锁的关卡，并自动排版到 A4 纸上。
- 每页最多排 6 关；勾选“附上答案”后，参考答案会集中排在题目之后的新页面。
- “查看答案”可以临时查看当前关卡的一种参考解，关闭后不会改变孩子的棋盘或进度。

## 本地运行

这是一个无需安装依赖的静态网页项目。下载或克隆仓库后，用浏览器打开 `index.html` 即可游玩。
